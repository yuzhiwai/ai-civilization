# AI与文明 —— 历史方向论文集

知乎专栏「AI与文明」（作者：微与之）的公开镜像。这里收录全部14篇正文、误读答疑与解释者提示词，供检索、引用与AI阅读。

## 核心主张

> **历史有方向，方向是共产主义。但方向不承诺到达，路需要每代人自己去走。**

- **历史有方向**——漂移的符号稳定且单一，不是随机漂移（反无方向论）。
- **方向是共产主义**——方向有名字、有内容：共产主义的内涵就是开放的最大化，三句（稀缺退出分配／生产资料不垄断／人不受限制发展）是其内容。量结构不量旗号。
- **不承诺到达**——渐近线非到站，机制给符号不给日期（反必然论）。
- **每代人自己去走**——概率与速率由参与者走出；每代人两件事：守住牌桌、让下一代在场（反宿命旁观）。

判据只有一条：**拒绝权**——人能否退出、错误能否被允许、位置能否自定。量结构不量旗号，对任何阵营一视同仁。

## 起点

《00_起点：1984与美丽新世界（2013年豆瓣书评原文）》——整套理论起于对美丽新世界式稳态（而非1984）的恐惧，这篇2013年的书评是全部论证的原始起点。按原样收录，其中“稳态”判决已被现行理论反转（见07篇定理五），修正史本身即是文献。
